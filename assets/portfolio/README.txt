HOW TO ADD PORTFOLIO PHOTOS
============================

1. Save each photo as a plain number: 1.jpg, 2.jpg, 3.jpg, 4.jpg ...
   (always lowercase ".jpg", no spaces, no other text in the filename)

2. Put them in this folder: assets/portfolio/

3. Push to GitHub. Vercel will redeploy automatically.

That's it — no HTML/code editing needed. The website checks this folder
and shows whatever numbered photos it finds.

TIPS
----
- Portrait orientation works best (roughly 4:5, e.g. 1200x1500px).
- Keep each file under ~500KB-1MB so the page stays fast — resize/compress
  before uploading if your phone photos are huge.
- The first 8 photos show right away; if you add more than 8, a
  "View All Work" button automatically appears to reveal the rest.
- Numbers don't need to be perfectly sequential — if you delete 5.jpg
  later, the rest still show fine. Just don't reuse a number for a
  different photo without replacing the old file.
- To remove a photo, just delete its file and push again.
